# ResNet-18 Image Classification: Cats vs Dogs

A deep learning project that uses **PyTorch and ResNet-18** to classify images into two categories: cats and dogs. The project includes model training, image prediction, and a Streamlit web application for interacting with the trained model.

## Project Overview

Image classification is a computer vision task that assigns a label to an input image. In this project, a ResNet-18 convolutional neural network (CNN) learns to distinguish between cat and dog images.

The project demonstrates a complete image classification workflow, from dataset preparation and model training to saving model weights and making predictions.

## Features

- Binary image classification: Cat vs. Dog
- ResNet-18 deep learning architecture
- PyTorch and Torchvision implementation
- Image preprocessing and tensor transformations
- Training and validation split
- Model checkpoint saving
- Image prediction using a trained model
- Interactive web interface using Streamlit

## Dataset

The project uses a Cats vs Dogs image dataset containing two categories:

- **Cat:** Images of cats.
- **Dog:** Images of dogs.

The source dataset contains approximately 25,000 images, with 12,500 cat images and 12,500 dog images.

### Dataset preprocessing

The training workflow uses the following configuration:

- Image size: 224 × 224 pixels
- Image channels: 3 (RGB)
- Training/validation split: 80% / 20%
- Random seed: 42
- Batch size: 16
- Labels: Cat = 0, Dog = 1

The dataset is loaded from the directory configured in `train.py`. Update the `DATA_DIR` path to match your own dataset location.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/wahidali4321/ResNet-Image-Classification.git
cd ResNet-Image-Classification
```

### 2. Create a virtual environment

On Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install torch torchvision pillow streamlit
```

Verify your PyTorch installation:

```bash
python -c "import torch; print(torch.__version__); print('CUDA available:', torch.cuda.is_available())"
```

The original development environment used CPU-based PyTorch.

## Configure the Dataset

Open `train.py` and locate the dataset path configuration:

```python
DATA_DIR = Path(
    r"C:\Users\DELL\Downloads\archive\train\train"
)
```

Replace the path with the location of your downloaded dataset.

Ensure the directory contains the expected cat and dog image files, such as `cat.*.jpg` and `dog.*.jpg`, as required by the dataset-loading code.

## Train the Model

Run the training script:

```bash
python train.py
```

The script prepares the images, initializes the ResNet-18 classifier, and runs the training workflow defined in the code.

Training time depends on the number of images, hardware, batch size, and number of epochs.

## Run the Prediction Script

To use the prediction workflow:

```bash
python predict.py
```

Follow the usage defined in `predict.py`. If the script requires command-line arguments, provide the image path and other required options specified by the implementation.

## Launch the Streamlit Application

Start the web interface:

```bash
streamlit run app.py
```

Streamlit will provide a local URL, typically:

```text
http://localhost:8501
```

Open the URL in your browser and use the interface to test image classification, provided that the application can locate a compatible trained checkpoint.

## Model Architecture: ResNet-18

ResNet-18 is a convolutional neural network that uses residual connections to help train deeper networks.

The model is adapted for a two-class classification task:

1. Load and preprocess the input image.
2. Pass the image through the ResNet-18 network.
3. Produce class scores for cat and dog.
4. Select the predicted class.
5. Display the classification result.
